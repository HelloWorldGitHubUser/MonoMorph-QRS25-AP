# MonoMorph Artifacts Package

Artifacts Package for the paper “MonoMorph: An Agentic Framework for Automated Monolith-to-Microservices Code Refactoring”.

## Description

This package includes the artifacts used in the qualitative and quantitative evaluations in the paper “MonoMorph: An Agentic Framework for Automated Monolith-to-Microservices Code Refactoring”.

The package provides:

* The resources used in the **qualitative evaluation** in [qualitative_evaluation_resources](qualitative_evaluation_resources).
* An anonymized version of the **evaluator responses** in [evaluator_responses](evaluator_responses). The directory is structured as follows: `evaluator_responses/[participant_codename]/[approach]/[benchmark].pdf`. Background questionnaire responses are at `evaluator_responses/[participant_codename]/Evaluator Background Questionnaire.pdf`.
* The artifacts used in the **quantitative evaluation** (RQ2 and RQ3) in [quantitative_evaluation](quantitative_evaluation).

## Quantitative Evaluation

The [quantitative_evaluation](quantitative_evaluation) directory contains all artifacts needed to inspect and reproduce the quantitative results reported in the paper. It is organized as follows:

```
quantitative_evaluation/
├── data/
│   ├── effort_metrics/          # Pre-computed refactoring effort metrics (CSV/JSON)
│   └── test_reports/            # Pre-computed test outcome reports (CSV)
│       └── raw/                 # Raw Surefire XML reports (monoliths, monomorph, microrefact)
├── generated_microservices/
│   ├── monomorph/               # Microservices generated by MonoMorph (zipped)
│   │   ├── 7ep-demo.zip
│   │   ├── jpetstore-6.zip
│   │   └── spring-petclinic.zip
│   └── microrefact/             # Microservices generated by MicroRefact (baseline, zipped)
│       ├── 7ep-demo.zip
│       ├── jpetstore-6.zip
│       └── spring-petclinic.zip
├── run_metadata/
│   ├── PII_NOTICE.md            # Notice about absolute paths in log files
│   └── monomorph/               # MonoMorph run artifacts (args, logs, per-service outputs)
│       ├── 7ep-demo/
│       ├── jpetstore-6/
│       └── spring-petclinic/
└── scripts/
    ├── rq2_monomorph.py         # RQ2 effort metrics — MonoMorph
    ├── rq2_microrefact.py       # RQ2 effort metrics — MicroRefact (baseline)
    ├── rq3_monomorph.py         # RQ3 test outcome equivalence — MonoMorph
    ├── rq3_microrefact.py       # RQ3 test outcome equivalence — MicroRefact (baseline)
    ├── compute_rq2_monomorph.py    # JSON → CSV for MonoMorph effort metrics
    ├── compute_rq2_microrefact.py  # JSON → CSV for MicroRefact effort metrics
    └── compute_rq3_reports.py       # Raw Surefire XML reports → CSV for RQ3
```

### Generated Microservices

Each zip archive in `generated_microservices/` contains the full source code of the refactored microservices for one benchmark application, including the `.git` history. Extracting an archive restores a git repository whose commit history was used to compute the refactoring effort metrics (RQ2).

- **`monomorph/`** — output of the MonoMorph correction agent. Each archive contains one subdirectory per microservice (e.g. `account/`, `catalog/`, `order/`), each being an independent git repository tracking the agent's incremental commits.
- **`microrefact/`** — output of the MicroRefact baseline tool. Each archive contains numbered microservice subdirectories (`0/`, `1/`, `2/`, …) within a single git repository whose history records the refactoring steps.

### Reproducing the Results

Each script in `quantitative_evaluation/scripts/` reads from the pre-computed data in `quantitative_evaluation/data/` and prints the LaTeX tables included in the paper to stdout. Run from the `scripts/` directory:

```bash
python rq2_monomorph.py
python rq3_monomorph.py
python rq2_microrefact.py
python rq3_microrefact.py
```

Requirements: Python 3 with `pandas` and `numpy`.

The pre-computed CSV files in `data/effort_metrics/` are the direct inputs to the RQ2 scripts. They can optionally be regenerated from the raw JSON files in the same directory by running the compute scripts:

```bash
python compute_rq2_monomorph.py    # regenerates monomorph_metrics.csv from monomorph_metrics.json
python compute_rq2_microrefact.py  # regenerates microrefact_metrics.csv from microrefact_metrics.json
```

The raw JSON files were produced by running the evaluation pipeline (computing metrics from the git history of the generated microservice repositories and running the test suites via Docker). That pipeline requires the `refacteval` library from the main repository and a working Docker installation.

The pre-computed CSV files in `data/test_reports/` (`monoliths.csv`, `monomorph.csv`, `microrefact.csv`) are the direct inputs to the RQ3 scripts. They can optionally be regenerated from the raw Surefire XML reports in `data/test_reports/raw/` by running:

```bash
python compute_rq3_reports.py      # regenerates monoliths.csv, monomorph.csv, microrefact.csv from raw/
```

This script is self-contained (only requires `pandas`) and does not depend on `refacteval` or Docker — the raw reports were produced by running the test suites via the `refacteval` testing pipeline, but parsing them into the summary CSVs only requires standard XML parsing.

## Disclaimer

The directory [qualitative_evaluation_resources](qualitative_evaluation_resources) is a near-identical version of the repository shared with the evaluation participants. For the sake of anonymity, the README and the static analysis files (`typeData.json`) have been modified to remove author and participant identifying information.
