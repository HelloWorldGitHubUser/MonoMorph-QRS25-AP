# MonoMorph Artifacts Package

Artifacts Package for the paper “Beyond Decomposition: a LLM-Powered Automated Approach to Refactoring Monoliths into Microservices”.

## Description

This package includes the artifacts used in the qualitative and quantitative evaluations in the paper “Beyond Decomposition: a LLM-Powered Automated Approach to Refactoring Monoliths into Microservices”.

The package provides:

* The resources used in the **qualitative evaluation** in [qualitative_evaluation_resources](qualitative_evaluation_resources).
* An anonymized version of the **evaluator responses** in [evaluator_responses](evaluator_responses). The directory is structured as follows: `evaluator_responses/[participant_codename]/[approach]/[benchmark].pdf`. Background questionnaire responses are at `evaluator_responses/[participant_codename]/Evaluator Background Questionnaire.pdf`.
* The artifacts used in the **quantitative evaluation** (RQ2 and RQ3) in [quantitative_evaluation](quantitative_evaluation).

## Quantitative Evaluation

The [quantitative_evaluation](quantitative_evaluation) directory contains all artifacts needed to inspect and reproduce the quantitative results reported in the paper. It is organized as follows:

```
quantitative_evaluation/
├── data/
│   ├── effort_metrics/          # Pre-computed refactoring effort metrics (CSV/JSON)
│   └── test_reports/            # Pre-computed test outcome reports (CSV)
├── generated_microservices/
│   ├── monomorph/               # Microservices generated by MonoMorph
│   │   ├── 7ep-demo/
│   │   ├── jpetstore-6/
│   │   └── spring-petclinic/
│   └── microrefact/             # Microservices generated by MicroRefact (baseline)
│       ├── 7ep-demo/
│       ├── jpetstore-6/
│       └── spring-petclinic/
└── scripts/
    ├── rq2_monomorph.py         # RQ2 effort metrics — MonoMorph
    ├── rq2_microrefact.py       # RQ2 effort metrics — MicroRefact (baseline)
    ├── rq3_monomorph.py         # RQ3 test outcome equivalence — MonoMorph
    ├── rq3_microrefact.py       # RQ3 test outcome equivalence — MicroRefact (baseline)
    ├── compute_rq2_monomorph.py    # JSON → CSV for MonoMorph effort metrics
    └── compute_rq2_microrefact.py  # JSON → CSV for MicroRefact effort metrics
```

### Reproducing the Results

Each script in `quantitative_evaluation/scripts/` reads from the pre-computed data in `quantitative_evaluation/data/` and prints the LaTeX tables included in the paper to stdout. Run from the `scripts/` directory:

```bash
python rq2_monomorph.py
python rq3_monomorph.py
python rq2_microrefact.py
python rq3_microrefact.py
```

Requirements: Python 3 with `pandas` and `numpy`.

The pre-computed CSV files in `data/` are the direct inputs to these scripts. They were produced by running the evaluation pipeline (computing metrics from the git history of the generated microservice repositories and running the test suites via Docker). That pipeline requires the `refacteval` library from the main repository and a working Docker installation.

## Disclaimer

The directory [qualitative_evaluation_resources](qualitative_evaluation_resources) is a near-identical version of the repository shared with the evaluation participants. For the sake of anonymity, the README and the static analysis files (`typeData.json`) have been modified to remove author and participant identifying information.
